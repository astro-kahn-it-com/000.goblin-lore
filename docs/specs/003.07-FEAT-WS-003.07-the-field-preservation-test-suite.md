---

### **I. FUNCTIONAL MANDATE**

**Strategic Goal** This feature implements `goblin-extract/scripts/round-trip-test.ts`, generating a
scene, applying a single scripted edit to exactly one field, running `extract()`, and asserting
every _other_ field remains byte-identical to its pre-edit value — across a matrix of scenarios
(editing only a beat's dialogue, only the Discomfort Curve, only the Setting). This is the
complementary guarantee to drift _detection_: proving the pipeline doesn't just notice changes, but
also doesn't lose or corrupt anything it shouldn't have touched.

**Business Value**

- **Protects the showrunner's trust in the entire Hybrid Authoring workflow:** A drift-detection
  system that's technically correct but that also quietly mangles unrelated fields on every save
  would be just as untrustworthy as one with no drift detection at all — this feature is what makes
  "edit one thing, only that thing changes" a tested guarantee, not an assumption.
- **Is the necessary counterpart to `FEAT-003.04`/`FEAT-003.05`/`FEAT-003.06`'s work:** Those
  Features prove genuine changes are caught. This Feature proves the absence of change is also
  correctly preserved — both halves are required for the extraction pipeline to be genuinely
  trustworthy.
- **Directly de-risks the MS-05 Hybrid Authoring Gate:** Every real showrunner interaction with
  `scene:draft`/`scene:commit` depends on this guarantee holding across realistic, everyday
  single-field edits, not just the adversarial fuzzing scenarios `FEAT-003.05` covers.

**Failure Criteria (Rollback Plan)**

- **Immediate Rollback:** If any scenario in the test matrix shows an untouched field changing value
  across the edit-and-extract cycle — this is a direct violation of the round-trip guarantee.
- **Suspension:** If the test matrix is found to only cover a narrow subset of realistic
  single-field edits (e.g., only dialogue edits, missing Setting or Production Notes edits) — pause
  and expand the matrix before considering this Feature representative of real showrunner usage.
- **Kill Switch:** None — a discovered field-preservation bug is a fixable defect in `extract()`,
  not an unrecoverable state; standard remediation applies, though with high urgency given the trust
  implications.

---

### **II. TECHNICAL CONSTRAINTS & REQUIREMENTS**

- **Test Matrix Scope:** At minimum three scenarios — dialogue-only edit (within one beat),
  Discomfort-Curve-only edit, Setting-only edit — each isolating exactly one field/section as the
  intended change.
- **Comparison Method:** Uses `FEAT-003.02`'s ledger diff tool (or an equivalent field-level
  comparator) to confirm zero unintended field differences between pre-edit and
  post-edit-and-extract states.
- **Realistic Fixtures:** Test scenarios are built against a real, previously-constructed outline
  from this project (e.g., "The Last Gate") rather than a minimal synthetic fixture, to exercise
  realistic formatting complexity.
