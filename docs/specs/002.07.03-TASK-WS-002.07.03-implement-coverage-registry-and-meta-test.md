### **I. TASK DESCRIPTION**

**User Story** As a Backend Engineer, I need to add a meta-test inside `residue-mandate.test.ts`
scanning resolution source files and flagging any implemented release mechanic absent from
`REGISTERED_RELEASE_MECHANICS`.

**Context & Value** Prevents un-registered release mechanics from slipping into production without
residue test coverage.

- **The Strategic Value:** Automates detection of release-mechanic testing gaps.
- **The Technical Challenge:** Constructing a meta-test cross-referencing module exports against
  registry entries.
- **The Architectural Constraints:** Must execute as part of standard Vitest test runs.
- **The Standard:** Zero un-registered mechanics allowed.

**Technical Constraints**

- **Test File:** Embedded in `worker-sower/test/residue-mandate.test.ts`.
